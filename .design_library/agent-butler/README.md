# Agent Butler Design System

Agent Butler 是一个面向本地 AI 管家的运维控制台（Dashboard）设计系统，服务于需要清晰层级、可信状态传达与紧凑信息密度的中后台监控面板。

> *"克制的专业管家风：暖白浅色画布 + 单一深青绿主色（传达健康/可信/克制），暖灰中性色，安静且降低饱和的语义状态色（绿/琥珀/红/蓝），8-10px 紧凑圆角，克制的阴影，清晰的层级；无霓虹、无黑客运维、无渐变紫卡片。"* — 品牌视觉基调

这套系统覆盖三块：**基础视觉**（颜色、字体、间距、圆角、阴影、边框与背景，全部落在 `colors_and_type.css`）、**六大核心组件**（Button / Card / Table / Chart / Navigation / Sidebar，聚合在 `components.css`），以及每个组件对应的 `preview/` 预览页与 `components/{slug}.json` 契约。所有 token 值均来自 `colors_and_type.css`，无任何虚构色值。

## 2. Content Fundamentals

### Voice & tone

这个产品的文案气质是「靠谱的克制」：一个专业、可靠的管家在最短的句子里把结论说清楚。语气中性、克制、可信，不带情绪化的感叹，也不用任何 emoji 或表情符号——它面向的是需要快速判断系统状态的运维场景，所以文案以「先给结论」为第一原则，用最短的大白话把状态和动作讲明白。没有说教式的长句，也没有夸张的营销话术；亲切感来自「帮我一下」式的动词短句，而不是亲昵的称呼或语气词。

### Concrete copy examples

- 运行状态：*"运行正常"*
- 主操作按钮：*"立即检查"*
- 补救动作：*"修复一下"*
- 详情入口：*"高级详情"*
- 通知/消息：*"消息通知"*
- 升级入口：*"版本升级"*
- 能力目录：*"技能库"*
- 安全模块：*"安全基线"*

### When generating copy

- **先给结论**：状态词放在最前，直接说「运行正常」，而不是「系统当前运行状况为正常」。
- **大白话 + 动词短句**：动作用「立即检查」「修复一下」这类口语化动词短语，长度控制在 2-4 字，适配按钮、徽标与表格单元格。
- **克制，不夸大**：不写「一键极速修复」「完美运行」，保持中性陈述。
- **无 emoji**：产品界面不使用任何表情符号；状态与情绪靠语义色与图标传达。
- **名词即模块**：用「技能库」「安全基线」这类中性名词直接命名模块，不用「智能」「超级」等形容词前缀。

## 3. Visual Foundations

### Color

品牌主色是深青绿 `#207466`（`--primary-600`），这是一个刻意压低饱和度的蓝绿色，视觉上同时传达健康、可信与克制，而不是科技蓝或运营黄。它承担主按钮、激活导航项、链接与强调动作等所有「需要被点到」的位置；焦点环 `--ring` 用更亮一档的 `#338f7e`（`--primary-500`），悬停态下主色加深到 `--primary-700` `#1d5f53`。主色阶共有 9 档，从极浅的 `#eef7f4`（`--primary-50`，用于激活导航项底色）一路延伸到接近墨色的 `#1a3f39`（`--primary-900`），但真正高频使用的是 50 / 400 / 500 / 600 / 700 这几档，其余档位主要为色阶完整度而存在。暗色模式下主色整体上移为 `--primary-400` `#53aa98`，画布落到 `#171412`。

中性色是一套 9 档的暖灰阶：画布底 `--background` 是带暖意的 `#faf9f7`，表面 `--surface` 与卡片 `--card` 用纯白 `#ffffff`，次级底 `--muted` 是 `#f3f1ee`，头发丝边框 `--border` 是 `#e7e3de`，正文前景 `--foreground` 落到近黑的暖灰 `#2a2622`，弱化文字 `--muted-foreground` 是 `#6f665e`。这套暖灰和深青绿主色在色温上同源（都偏暖、偏低饱和），所以白卡片叠在暖白画布上不会发冷。

语义色同样遵循「安静、降饱和」的调性：成功 `#3a6b4c`、警告 `#8f5c28`、危险 `#8a3f37`、信息 `#3d5f7f`，四者都不是刺眼的信号色，而是各自主色系里被压暗的中性档，用于徽标底色 + 深色文字的组合，而非大面积填充。图表用色从同一套 token 派生：`--chart-1` 即主色 `#338f7e`，`--chart-2` 是信息蓝 `#4e7397`，其余为成功绿、警告琥珀与中性暖灰，保证图表与 UI 同源不打架。

### Typography

标题与展示字体用 **Manrope**（`--font-heading` / `--font-display`），这是一款几何感较强的无衬线体，负责 display 与 h1-h4 全部层级，字重集中在 700（display/h1）与 600（h2/h3/h4）；正文用 **Inter**（`--font-body`），承担 body、lead 与 caption，字重 400（正文/导语）与 500（caption）。数值与代码用 **JetBrains Mono**（`--font-mono`），专门用于指标数值、表格中的计数等需要等宽对齐的位置，字重 400-500。三者均通过 Google Fonts 的 `@import` 引入，离线与中文字符的回落策略见文末 Caveats。

字号是一个偏紧凑的仪表盘阶梯：display 40px、h1 32px、h2 26px、h3 22px、h4 18px，正文 body 15px、导语 lead 17px、辅助 caption 12px、等宽 mono 13px。行高随字号增大而收紧——display 仅 1.15、h1 1.2，到 body 才放开到 1.6、lead 1.65，这是典型的数据面板做法：大标题紧排以压低首屏高度，正文放宽以保长文可读。字间距整体不做处理，仅 display 设 `-0.01em` 轻微收紧，侧栏分组标签用 `0.04em` 拉开。

### Spacing

间距以 4px 为基准单位，token 为 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（`--space-1` 到 `--space-8`）。这套数值刻意只取 4 的整数倍、且跳过 20 / 28 / 36 / 40 等中间档，让布局在紧凑的前提下保持可预测。控件高度与此对齐：按钮小 / 中 / 大分别是 32 / 40 / 48px，输入框 36px，图标三档 16 / 20 / 24px。卡片内边距统一用 `--space-5`（24px），表格单元格用 `--space-3` / `--space-4`（12 / 16px）控制密度。

### Radius

圆角走「紧凑但不过硬」的路线，共四档：`8px`（`--radius-sm`）给按钮、表格操作、面包屑项这类小控件；`10px`（`--radius-md`）给按钮默认态、表格容器与导航项；`12px`（`--radius-lg`）给卡片、页面头与侧栏这类大表面；`9999px`（`--radius-full`）只留给徽标、状态圆点与侧栏激活指示条这类胶囊/圆点形态。整体落在 8-10px 区间，没有大圆角的软萌感，也没有直角运维工具的冷硬感——正好是「克制」的具象化。

### Shadow / Elevation

阴影哲学是「克制的分层」：卡片在静止时几乎不靠阴影，而是靠 1px 头发丝边框 + 极浅的 `--shadow-1`（`0 1px 2px rgba(42,38,34,0.06), 0 1px 1px rgba(42,38,34,0.04)`）区分于画布。真正的阴影只服务于「浮起」时刻，共五层：卡片悬停 `--shadow-2`（`0 4px 8px -2px rgba(42,38,34,0.10)`）、浮层 `--shadow-3`（`0 8px 24px -8px rgba(42,38,34,0.16)`）、模态 `--shadow-4`（`0 16px 40px -12px rgba(42,38,34,0.22)`）、遮罩 `--shadow-5`（`0 24px 60px -20px rgba(42,38,34,0.28)`）。注意所有高层阴影都带负向 spread，让阴影向上向内收缩、只从底部溢出，避免常见的「四周发黑」脏感。暗色模式整组阴影换成纯黑、透明度拉高到 0.40-0.65。

### Borders & Backgrounds

边框是这套系统的隐形骨架：默认 1px、颜色 `#e7e3de`（`--border`），几乎每一处卡片、表格、侧栏、secondary 按钮都用它。背景层次是「暖白画布 `#faf9f7` 之上叠白表面 `#ffffff`」，次级容器用 `--muted` `#f3f1ee` 兜底。状态卡片没有用满底色，而是用 4px 的左侧色条（`border-left` 对应 success / warning / error 色）在视觉上给出轻量的状态提示。交互动效极简：背景/边框过渡 0.15s，悬停多用 `filter: brightness()` 轻微提亮或压暗，不引入位移动画。

## 4. Component Patterns

| slug | name | key insight |
|---|---|---|
| button | Button | 主 CTA 是实心主色的「立即检查」；禁用态不用半透明，而是 muted 灰底 + 弱化文字，保持可读但明确不可点 |
| card | Card | 状态卡用 4px 左侧色条区分成功/告警/危险，右上角胶囊徽标承载「运行正常」式状态词 |
| table | Table | 数据密集表格用头发丝分隔 + 悬停 `brightness(.97)`，状态列直接内嵌胶囊徽标，避免额外色块 |
| chart | Chart | 指标数值用 JetBrains Mono 等宽呈现，趋势线与迷你 spark 统一主色，语义变化才换状态色 |
| navigation | Navigation | 页面头承担标题 + 描述 + 动作三者，面包屑克制地只用灰字，当前项才加深 |
| sidebar | Sidebar | 240px 可折叠到 64px，激活项用左侧 3px 主色竖条 + 浅青绿底色标记当前位置 |

## 5. Index

- `README.md` — 本文件，品牌叙事与视觉基础（人工设计者先读这里）
- `colors_and_type.css` — 颜色/字体/间距/圆角/阴影/边框的全部 CSS token，单一变量源
- `css.json` — 结构化 token 表示，供程序化消费
- `components.css` — 从 `preview/` 页面抽取聚合的组件 CSS
- `components/index.json` — 组件索引、跨组件模式与摘要
- `components/{slug}.json` — button / card / table / chart / navigation / sidebar 六份组件契约
- `preview/component-{slug}.html` — 各组件的小型预览卡片

## 6. Caveats / known substitutions

1. **字体通过 Google Fonts CDN 引入**（Manrope / Inter / JetBrains Mono），离线环境会回落到 token 中声明的 `sans-serif` / `monospace` 通用族。更关键的是 Inter 与 JetBrains Mono 不含 CJK 字形，面板里的中文实际由系统默认中文黑体渲染，因此在不同操作系统上中文字形会有差异，需要时应在宿主侧补一份中文字体。
2. **全部 token 均为 AI 推断值**：`colors_and_type.css` 里每个变量都标注 `AI-generated`，本设计系统是从品牌上下文重建的，没有 Figma 源文件做数值佐证。色阶中间档、语义色、阴影数值与图表色都属于推断，落地时可按真实品牌资产校准。
3. **`components.css` 存在重复定义**：Navigation 段落重新定义了 `.btn` / `.btn-primary` / `.btn-ghost`，与 Button 段落规格不完全一致（如 `min-width`、`font-weight`、`border-radius` 引用）。消费时以 Button 段落为准，Navigation 段落中的按钮类仅作为页面头上下文的历史遗留看待。
4. **图标无源**：本库只定义了 16 / 20 / 24px 三档图标尺寸 token，没有内置图标 SVG，实际图标需自行准备并按尺寸 token 约束。
5. **暗色模式为附加产物**：BrandFile 的品牌基调只描述了浅色画布，`.dark` 块属于推断出的暗色变体，非品牌原始规范的一部分。
