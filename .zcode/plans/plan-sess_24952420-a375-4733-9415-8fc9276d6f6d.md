**集成 skills-manager 到 Butler 技能管理（CLI 服务化方案）**

工具事实：xingkongliang/skills-manager（MIT）提供中央技能库、Git/zip/本地安装、deploy 部署到 agent 目录（symlink/复制、支持自定义目录与 adopt 收编）、check/update 更新追踪；无 HTTP 接口，但提供 `skills-manager-cli`（Release 有 Linux x64 二进制，`--json` 输出、`--dry-run`、破坏性命令 `--yes`）。

**Phase 0 集成探针**（实施第一步）：WSL 下载 Release Linux x64 CLI 实测——`--help`/`skills list --json`/`agents` 注册自定义目录/临时目录全链路 install→deploy→check/`TARGET_CONFLICT` 与 `adopt` 行为；确认 glibc 兼容与 watch 容器内可运行。所有端点解析按实测 `--json` 形状编写。

**Phase 1 打包**：watch Dockerfile 固定 release 版本下载 CLI 至 /usr/local/bin（构建参数可覆盖）；中央库持久化到数据卷 /home/butler/data/skills-manager；确认镜像含 git。

**Phase 2 watch 服务与端点**（TDD）：新模块 `apps/watch/src/skills-manager.ts`（execFile 封装、--json 解析、错误码映射、破坏性操作 dry-run+confirmed 二段式）；端点：`GET /api/skills-manager/status`、`POST .../install {source}`、`POST .../deploy|undeploy {name,mode}`、`GET .../updates`、`POST .../update {name}`、`POST .../adopt {dir}`；web 全部加代理（鉴权/503 降级照现有模式）。Hermes 部署目标 = ~/.hermes/skills（watch 容器 rw 挂载）。

**Phase 3 UI**：/skills 页新增「技能库」标签：状态卡（CLI 缺失→安装指引）、库列表（名称/来源/版本/部署状态/更新徽章）、安装表单（Git URL/zip → dry-run 预览 → 确认安装 → 部署到 Hermes）、一键 update。

**测试与验证**：CLI 封装注入 runner 单测；http/web 端点测试照既有模式；部署后对本机 Hermes 真实联调（GitHub 安装→部署→技能页可见→update 检查）；AGENTS.md/README 增补；版本 bump + CHANGELOG + 推送 GitHub。
